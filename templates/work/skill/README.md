# Reportes de Skills (`overview/work/skill/`)

> Cada skill instalada en `.skill/` persiste aquí su auditoría activa como `<slug>.md` (ej. `security.md`, `i18n.md`).
> Esquema estándar (6 columnas): `ID | Tipo | Estado | Resumen | Evidencia/Ruta | Acción Requerida`.
> `$boot` marca `skills-pendientes` si una skill instalada no tiene reporte o supera 7 días sin actualizar.
> Al resolver un ítem en `work.md`, marcar la fila origen como `superseded` con el ID resuelto.
