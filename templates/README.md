# Inicializar `overview/`

Copiar contenido de este directorio a `overview/` en raíz del proyecto Flutter (`$boot` / ejecuta `.agents`). Conservar archivos en Git del **proyecto**, no del submódulo `.agents`.

```text
overview/
├── context/
├── history/
├── workflows/
├── work/
│   ├── tasks.md
│   ├── pendientes.md
│   └── deuda_tecnica.md
├── architecture.md
├── architecture/
├── learning.md
├── session.md
├── work.md
├── work_review.md
└── trackers/
    ├── architecture.md
    ├── progress.md
    ├── content_gemini.md
    ├── content_claude.md
    ├── content_gpt.md
    └── content_verified.md
```
